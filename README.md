Blue Team SOC Cybersecurity Practice Lab
========================================

A practical, evidence-based cybersecurity portfolio project focused on Blue Team security operations, Windows event monitoring, threat detection, incident triage, threat hunting and incident response.

Project environment
-------------------
- Windows 11 laptop with 4 GB RAM
- Native Windows Event Viewer and PowerShell
- No Azure subscription or virtual machines required
- Additional tools introduced only after compatibility and resource checks

Learning objectives
-------------------
1. Inspect and interpret Windows security events.
2. Distinguish normal activity from potentially suspicious events.
3. Investigate authentication, processes and network activity.
4. Record evidence, observations and response recommendations.
5. Write clear SOC investigation reports.

Training roadmap
----------------
- Day 1: Windows security event monitoring and baseline investigation
- Day 2: Network traffic analysis
- Day 3: Network service discovery in an authorised lab
- Day 4: Vulnerability assessment and prioritisation
- Day 5: Authentication attack detection using safe test data
- Day 6: Malware evidence analysis using safe datasets
- Day 7: Endpoint threat detection
- Day 8: Incident response simulation
- Day 9: Threat hunting and MITRE ATT&CK mapping
- Day 10: Final investigation report and portfolio review

Progress

Day 1: In progress. Evidence and findings have not yet been collected.

Evidence handling
-----------------
Screenshots and logs must be reviewed before publication. Redact usernames, device identifiers, IP addresses, email addresses, access tokens and other sensitive information. Do not publish raw private security logs.
